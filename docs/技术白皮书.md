# 用声无恙 UnVoiceClone 技术白皮书

UnVoiceClone 面向生成式伪造语音欺骗场景，采用主动扰动与身份替换策略，让公开传播的语音在人耳听感保持自然的同时，使黑盒语音克隆模型难以复刻真实声纹。

## 核心方法

1. 动态集成说话人编码器：融合 ECAPA-TDNN、GE2E、d-vector 与 Style Encoder 表征。
2. KL 散度异性身份替换：选择与原始声纹差异最大的匿名目标表征。
3. WaveGlow 对抗生成：将高斯扰动引入声码器生成阶段。
4. 基音可控调节：约束基音变化范围，降低听感损伤。
5. SAM 扰动优化：提升未知模型与平台压缩场景下的鲁棒性。
