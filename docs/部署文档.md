# UnVoiceClone 部署文档

## 1. GitHub Pages 部署静态前端

本项目已将静态前端页面放置在仓库根目录，可直接通过 GitHub Pages 发布前端展示页面。

### 部署步骤

1. 将项目上传到 GitHub 仓库，例如：`UnVoiceClone`。
2. 打开仓库页面，进入 `Settings` → `Pages`。
3. 在 `Build and deployment` 中选择 `Deploy from a branch`。
4. 分支选择 `main`，目录选择 `/root`。
5. 点击保存，等待 GitHub Pages 完成部署。

部署成功后，访问地址格式如下：

```text
https://你的GitHub用户名.github.io/UnVoiceClone/
```

### Pages 可直接访问的页面

- `index.html`：系统官网主页
- `auth.html`：登录页
- `dashboard.html`：系统控制台
- `audio-defend.html`：音频防御页面
- `video-defend.html`：视频防御页面
- `audio-transform.html`：音频转换测试页面
- `audio-synthesis.html`：音频合成测试页面
- `settings.html`：系统设置页面

## 2. 本地运行静态前端与后端服务

### 静态前端 + Flask 后端

1. 安装 Python 3.8~3.10。
2. 执行 `pip install -r requirements.txt`。
3. 执行 `python start_system.py`。

启动后可访问：

- 静态前端：`http://127.0.0.1:8080`
- 后端健康检查：`http://127.0.0.1:5000/api/health`

## 3. 端口配置

默认静态前端端口为 `8080`，后端 API 端口为 `5000`，可在 `configs/server_config.yaml` 中调整。

## 4. 模型配置

系统模型权重存放于 `models/pretrained/` 目录。模型路径、推理设备、加载参数和算法超参数分别由 `backend/config/model_config.py` 与 `configs/algorithm_params.yaml` 管理。部署时请根据实际模型文件、设备环境和推理需求完成配置。
