# UnVoiceClone 部署文档

## 本地部署

1. 安装 Python 3.8~3.10。
2. 执行 `pip install -r requirements.txt`。
3. 将预训练权重放入 `models/pretrained/`。
4. 执行 `python start_system.py`。

## 端口配置

默认静态前端端口为 `8080`，后端 API 端口为 `5000`，可在 `configs/server_config.yaml` 中调整。

## 模型配置

系统模型权重存放于 `models/pretrained/` 目录。模型路径、推理设备、加载参数和算法超参数分别由 `backend/config/model_config.py` 与 `configs/algorithm_params.yaml` 管理。部署时请根据实际模型文件、设备环境和推理需求完成配置。
