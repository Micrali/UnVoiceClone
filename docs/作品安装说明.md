# 作品安装说明

## 1. 项目基本信息

- 项目全称：用声无恙 - UnVoiceClone 面向生成式伪造语音欺骗的鲁棒主动防御系统
- 项目简称：UnVC
- 推荐 GitHub 仓库名：`UnVoiceClone-System`
- 推荐仓库地址：`https://github.com/UnVoiceClone/UnVoiceClone-System`
- 项目类型：Web 端声纹隐私主动防御系统

## 2. 环境要求

### 基础环境

- Python 3.8 ~ 3.10，推荐 Python 3.9
- Windows 10/11、Ubuntu 18.04+、macOS 均可
- 推荐浏览器：Chrome、Edge、Firefox

### 可选环境

- Node.js 18+ LTS：仅在运行 Vue3 开发版前端时需要
- FFmpeg：真实音视频转码处理时建议安装
- NVIDIA GPU + CUDA：接入真实深度学习模型推理时建议配置

## 3. 安装步骤

### 3.1 克隆仓库

```bash
git clone https://github.com/UnVoiceClone/UnVoiceClone-System.git
cd UnVoiceClone-System
```

如果当前是在本地交付目录中运行，可直接进入项目根目录。

### 3.2 创建虚拟环境

Windows：

```bash
python -m venv unvc_env
unvc_env\Scripts\activate
```

Linux/macOS：

```bash
python -m venv unvc_env
source unvc_env/bin/activate
```

### 3.3 安装依赖

```bash
pip install -r requirements.txt
```

如需 GPU 加速版本 PyTorch，可根据本机 CUDA 版本到 PyTorch 官网选择对应安装命令。例如 CUDA 11.7：

```bash
pip install torch==2.0.1+cu117 torchaudio==2.0.2+cu117 --index-url https://download.pytorch.org/whl/cu117
```

## 4. 启动方式

### 方式一：一键启动

```bash
python start.py
```

根据提示选择启动模式。推荐选择“传统静态页面模式”，该模式无需 Node.js，适合比赛展示、答辩演示和截图。

### 方式二：直接启动完整演示系统

```bash
python start_system.py
```

该命令会同时启动：

- 静态前端服务：`http://127.0.0.1:8080/index.html`
- Flask 后端服务：`http://127.0.0.1:5000/api/health`

### 方式三：运行 Vue3 开发版前端

```bash
cd frontend/vue_project
npm install
npm run dev
```

Vue 开发版默认访问：`http://127.0.0.1:5173/`

## 7. 常见问题

### Q1：启动后无法访问页面

请检查 8080 和 5000 端口是否被占用。如果端口被占用，可关闭占用进程，或修改 `configs/server_config.yaml`。

### Q2：登录失败

请使用默认账号 `admin` 与密码 `admin123`。当前版本为演示系统，未接入真实数据库。

### Q3：上传音视频后没有真实生成防御文件

当前仓库版本是比赛展示与工程骨架版本，后端已经预留真实算法接入接口；在未配置完整预训练模型时，系统会执行模拟推理流程并返回评估结果。

### Q4：Vue 前端无法启动

请确认已经安装 Node.js 18+，并在 `frontend/vue_project/` 目录下执行 `npm install` 后再运行 `npm run dev`。
