# 开源代码与组件使用情况说明

## 1. 项目代码总体说明

本项目名称为 **用声无恙 - UnVoiceClone 面向生成式伪造语音欺骗的鲁棒主动防御系统**，简称 **UnVC**。项目围绕“公开音视频中的声纹隐私主动保护”这一核心目标完成研发，形成了包含前端交互、后端服务、音视频处理、核心算法、模型管理、配置管理、测试验证与项目文档在内的完整工程体系。

项目仓库代码按照功能职责进行模块化组织，各部分之间通过清晰的接口完成协同：前端负责用户交互与结果展示，后端负责 API 服务、文件任务调度和业务流程编排，核心算法模块负责声纹防御、扰动生成、身份替换与评估计算，工具层负责音视频预处理、模型加载、指标统计与并行任务处理。

| 控制台看板 | `dashboard.html` | 展示累计防御次数、今日处理数、防御成功率、系统可用性、历史处理记录等数据。 |

## 5. 核心算法代码说明

核心算法部分位于 `core_algorithm/`，围绕“防御有效性、音频保真度、压缩鲁棒性、未知模型泛化性”四个目标组织实现。

| 模块 | 文件 | 功能说明 |
|------|------|----------|
| 动态集成说话人编码器 | `speaker_encoder_integration.py` | 集成多类说话人编码器表征，对输入语音提取稳定声纹嵌入。 |
| KL 散度身份替换 | `kl_divergence_identity_swap.py` | 基于 KL 散度计算源声纹与候选匿名目标声纹的差异，选择最优替换方向。 |
| WaveGlow 对抗生成 | `waveglow_adversarial_generator.py` | 在声码器生成流程中加入可控扰动，生成具有抗克隆能力的防御语音。 |
| 基音可控调节 | `pitch_controllable_adjust.py` | 对防御后语音的基音变化范围进行约束，保持听感自然。 |
| 扰动优化 | `perturbation_optimizer.py` | 通过梯度正则化、裁剪和 SAM 思路约束扰动幅度与泛化能力。 |
| 嵌入损失 | `loss/embedding_loss.py` | 约束源语音与防御语音在声纹嵌入空间中的目标关系。 |
| 软约束损失 | `loss/soft_constraint_loss.py` | 控制防御扰动与原始信号之间的差异，平衡音质与防御强度。 |
| 高斯分布逼近损失 | `loss/gaussian_approximation_loss.py` | 对扰动分布进行正则化，提高平台压缩与传输后的稳定性。 |

## 6. 模型与数据边界说明

项目中的 `models/pretrained/` 用于放置预训练模型权重和自研训练权重。为了便于部署与版权管理，仓库代码与大体积权重文件分离管理。模型加载逻辑由 `models/model_loader.py` 统一封装，后端和算法服务通过配置文件指定模型路径。

涉及的模型类型包括：

- 说话人编码器模型：用于提取源语音和目标语音的声纹嵌入；
- 声码器模型：用于生成或重建防御后音频；
- 人声定位模型：用于区分视频或音频中的人声、音乐和噪声片段；
- 评估模型：用于计算克隆相似度、防御成功率和说话人保真度。

项目不在仓库中直接包含未经授权的大型预训练权重，所有模型权重均通过公开来源、自研训练或合法授权方式获取。

## 8. 自研代码与开源组件边界

### 8.1 自研内容

本项目自研内容主要包括：

1. 面向声纹隐私主动防护的整体系统架构；
2. 音频防御、视频防御、音频转换测试、音频合成测试的完整业务流程；
3. Flask 后端 API 组织、任务调度逻辑和文件处理流程；
4. 前端页面结构、交互流程、样式设计和结果展示逻辑；
5. KL 散度身份替换策略、扰动优化流程、损失函数设计和多编码器集成策略；
6. 系统配置管理、模型加载封装、指标计算和测试用例。

### 8.2 开源组件使用边界

1. Flask、Vue、Vite、Element Plus 等组件仅用于搭建 Web 服务与前端工程，不包含项目核心业务逻辑；
2. PyTorch、torchaudio、numpy、scipy 等组件用于张量计算、音频处理和模型推理，不直接决定项目的防御策略；
3. ffmpeg-python、moviepy、pydub、opencv-python 用于音视频格式处理、轨道抽取和文件封装，不涉及核心算法创新；
4. ECharts 用于数据可视化展示，图表数据、指标含义和业务展示逻辑由项目自研实现；
5. 所有第三方依赖均通过标准包管理工具安装，不对其源码进行未授权修改，不移除原有版权声明。

### 8.3 模型使用边界

项目可接入公开预训练说话人编码器、声码器和人声定位模型。预训练模型主要承担基础特征提取或音频重建能力，项目的声纹主动防御策略、身份替换逻辑、扰动约束、鲁棒优化和评估流程由项目代码实现。

对于开源预训练模型，本项目遵守其对应开源协议和模型发布方要求；对于自研训练权重，由项目团队自行训练、调参和管理。
