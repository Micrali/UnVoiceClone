# 用声无恙-UnVoiceClone 前端生成/优化问答

本文件用于回答假前端生成工具或前端优化人员在开始设计前需要明确的 5 个问题，可直接作为产品需求输入。

## Q1：请简述您的产品是什么，它解决了什么问题？

**产品名称**：用声无恙 - UnVoiceClone，简称 UnVC。

**产品定位**：UnVC 是一个面向生成式伪造语音欺骗的鲁棒主动防御系统，核心目标是在音频或视频公开传播前，对其中的人声进行“人耳无明显差异、机器难以克隆”的主动防护处理。

**解决的问题**：

随着语音克隆、AI 配音、TTS 与语音转换技术快速发展，攻击者只需要获取用户在短视频、直播、会议录音或社交平台中公开的一小段语音，就可能克隆出高度相似的声音，用于电信诈骗、身份冒充、舆情造谣、金融欺诈或声音版权侵权。传统深伪检测通常只能在伪造内容出现后进行识别，属于事后被动防御，无法阻止真实声纹被采集和滥用。

UnVC 的价值在于把防线前移：用户在上传、发布或共享音视频之前，系统先对人声加入可控防御扰动，使音频在听感上保持自然，但会显著干扰后续语音克隆模型的声纹提取与身份建模，从源头降低声纹隐私泄露风险。

## Q2：您的目标用户是谁？他们有哪些特点和需求？

目标用户主要包括以下几类：

1. **普通个人用户**
   - 特点：经常在短视频、社交媒体、直播、播客、聊天软件中发布语音或视频。
   - 需求：希望在不影响正常分享与观看体验的前提下，避免自己的真实声纹被他人采集、克隆和冒用。

2. **公众人物、政务人员、企业高管、主播与内容创作者**
   - 特点：声音公开曝光度高，被 AI 冒充的风险更高。
   - 需求：需要对公开视频、访谈、直播切片、宣传内容进行批量声纹防护，降低伪造语音带来的声誉、法律与安全风险。

3. **金融机构、客服中心、企业安全部门**
   - 特点：存在语音验证、电话沟通、远程身份确认等业务场景。
   - 需求：希望降低 AI 语音诈骗、冒充领导转账、远程身份欺骗等风险，并形成可审计的安全处理流程。

4. **媒体机构、音频平台与版权方**
   - 特点：拥有大量主播、配音、演员、播客等声音资产。
   - 需求：需要对外发布的音视频内容进行声音版权保护，防止声音被恶意复刻与商业滥用。

用户共同特点是：不希望操作过于复杂，期望“一键上传、一键防御、可视化评估、直接下载”，同时对音质、处理速度、隐私保护与平台兼容性有较高要求。

## Q3：您希望产品包含哪些核心功能？

产品核心功能包括：

1. **官网主页展示**
   - 展示产品定位、核心痛点、技术创新、性能指标、应用场景、团队信息与 GitHub 开源入口。
   - 风格应突出 AI 安全、声纹隐私保护、科技感与可信赖感。

2. **用户登录认证**
   - 提供演示账号登录。
   - 登录后进入系统控制台。

3. **控制台数据看板**
   - 展示累计防御文件数、今日处理数、平均防御成功率、平均处理时长、系统可用性、拦截克隆风险次数等指标。
   - 展示近 7 天处理趋势、不同场景防御成功率分布、历史处理记录与系统状态。

4. **音频防御功能**
   - 支持 MP3/WAV 文件上传。
   - 支持轻度防护、标准防护、深度防护参数选择。
   - 展示原始音频与防御后音频波形、播放控件、处理耗时、防御成功率、说话人相似度等评估结果。
   - 支持下载防御后音频。

5. **视频防御功能**
   - 支持 MP4/AVI 文件上传。
   - 自动提取视频音轨中的人声片段进行防御处理。
   - 保留原视频画面质量，重新合成防御后视频。
   - 展示原始视频、防御后视频、人声波形与下载入口。

6. **防御效果在线测试**
   - 音频转换测试：上传原始音频和防御后目标音色，模拟语音转换克隆攻击。
   - 音频合成测试：输入文本并上传目标音色，模拟 TTS 克隆攻击。
   - 输出克隆相似度变化、风险等级与防御报告。

7. **系统设置与报告导出**
   - 配置默认防护等级、推理设备、上传大小、模型状态。
   - 支持导出处理报告或评估数据。

## Q4：您是否有参考的产品或设计风格偏好？

参考风格包括：

- 作品主页范例：https://teminyang.github.io/EtherSentinel/
- 语音安全产品参考：https://optimiscs.github.io/SoundGuardian/
- 语音安全产品参考：https://optimiscs.github.io/SoundGuard/
- 假前端参考：https://leqiyyy.github.io/EtherSentinel_mode/

设计偏好：

1. **整体风格**
   - 深蓝色/黑蓝色科技风。
   - 适当使用青蓝色、紫色、荧光蓝渐变作为强调色。
   - 页面需要有 AI 安全产品、网络空间安全、声纹隐私保护的专业感。

2. **视觉元素**
   - 使用卡片化布局、玻璃拟态、渐变边框、发光按钮、数据大屏样式。
   - 首页 Hero 区可以加入“原始音视频 → UnVC 防御 → 安全音视频 → 克隆失效”的流程动效图。
   - 图表区域使用 ECharts 风格的数据可视化。

3. **页面结构**
   - 官网主页可参考 EtherSentinel 的分区式长页面：Hero、痛点、技术、指标、功能、场景、页脚。
   - 功能页可参考安全控制台结构：顶部导航 + 侧边栏 + 指标卡片 + 图表 + 表格。

4. **交互体验**
   - 强调低门槛、一键式操作。
   - 上传区需要支持拖拽视觉效果。
   - 处理状态需要有明确反馈，如“上传中、处理中、处理完成、可下载”。

## Q5：您的产品是面向网页端还是移动端/App？

当前产品主要面向 **网页端 Web 应用**。

优先适配：

- 桌面端浏览器：Chrome、Edge、Firefox、Safari。
- 常见分辨率：1366×768、1440×900、1920×1080。
- 需要兼容平板和手机浏览器的响应式访问，但移动端不是第一优先级。

产品形态分为两类：

1. **静态官网与功能演示版**
   - 目录：`frontend/web_static/`
   - 技术：HTML + CSS + JavaScript
   - 特点：零依赖、可直接通过 GitHub Pages 或本地静态服务器访问，适合比赛展示、作品效果图截图、答辩演示。

2. **Vue3 开发版**
   - 目录：`frontend/vue_project/`
   - 技术：Vue3 + Vite + Element Plus + Pinia + Vue Router + Axios
   - 特点：适合后续二次开发、组件化维护与真实产品迭代。
