# 作品效果图说明

本项目的作品效果图建议直接使用本地运行后的网页截图，符合“网站截图即可”的要求。

## 1. 推荐截图页面

| 截图名称 | 页面地址 | 截图重点 |
|----------|----------|----------|
| 官网主页首屏 | `http://127.0.0.1:8080/index.html` | 产品名称、Slogan、核心指标、UnVC 防御流程 |
| 技术创新展示 | `http://127.0.0.1:8080/index.html` | 行业痛点、四大技术创新、性能对比图表 |
| 控制台看板 | `http://127.0.0.1:8080/dashboard.html` | 统计卡片、趋势图、功能入口、历史记录 |
| 音频防御页面 | `http://127.0.0.1:8080/audio-defend.html` | 文件上传、防御参数、双波形、评估结果 |
| 视频防御页面 | `http://127.0.0.1:8080/video-defend.html` | 视频上传、视频预览、人声波形、防御结果 |
| 防御测试页面 | `http://127.0.0.1:8080/test-defend.html` | 音频转换测试、TTS 合成测试、评估报告 |
| 系统设置页面 | `http://127.0.0.1:8080/settings.html` | 模型状态、参数配置、报告导出 |

## 2. 截图建议

- 使用 Chrome 或 Edge 浏览器。
- 分辨率建议为 1920×1080 或 1440×900。
- 浏览器缩放保持 100%。
- 截图前先运行：

```bash
python start_system.py
```

- 若只需要静态页面效果图，也可以直接用浏览器打开 `frontend/web_static/index.html` 等文件。

## 3. PPT 中的呈现方式

建议在 PPT 中按以下顺序展示：

1. 官网主页截图：说明产品整体定位。
2. 控制台截图：说明系统具备数据可视化与管理能力。
3. 音频防御截图：说明核心功能一。
4. 视频防御截图：说明核心功能二。
5. 防御测试截图：说明效果验证闭环。

## 4. GitHub Pages 部署建议

如需把静态前端发布为线上作品主页，可将 `frontend/web_static/` 的内容部署到 GitHub Pages。

推荐方式：

1. 新建一个 GitHub 仓库，例如 `UnVoiceClone-Page`。
2. 将 `frontend/web_static/` 下的 HTML、CSS、JS 文件上传到仓库根目录。
3. 在仓库 Settings → Pages 中选择 `main` 分支和根目录。
4. 发布后即可得到类似以下格式的访问地址：

```text
https://你的用户名.github.io/UnVoiceClone-Page/
```
